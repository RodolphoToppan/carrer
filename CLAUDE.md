# Instructions for Claude

Before working on this repository, read **`AGENTS.md`** completely.

`AGENTS.md` is the canonical source of truth for all AI agents.

It contains:

* product identity and objectives
* mandatory principles
* rules for working in this repository
* policies against repository clutter
* completion criteria
* architecture preservation guidelines

After reading `AGENTS.md`, consult these documents as needed:

* `docs/product/vision.md` — product vision
* `docs/product/principles.md` — product principles
* `docs/product/glossary.md` — canonical glossary
* `docs/development/repository-policy.md` — repository maintenance policy
* `docs/specs/*.md` — approved architecture specifications
* `PROJECT_CONTEXT.md` — project history and current sprint

## Key Reminders

* **Do not create status files** (STATUS.md, SUMMARY.md, PROGRESS.md, etc.)
* **Do not create session notes** or execution logs in the repository
* **Present results only in your final response**
* **Remove temporary files** after task completion
* **Update canonical documentation only when changes affect contracts, architecture, or permanent behavior**

When in doubt, re-read `AGENTS.md`.
